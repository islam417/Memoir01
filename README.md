# مذكرة الدرس التفاعلية (PWA)

## طريقة الرفع على GitHub Pages

1. أنشئ مستودع (repository) جديد على GitHub، أو استخدم مستودعك الحالي (مثل `islam417.github.io`).
2. ارفع كل الملفات الموجودة في هذا الأرشيف (`index.html`, `manifest.json`, `sw.js`, مجلد `icons`) إلى المستودع.
   - إن كان المستودع الرئيسي `username.github.io`: ضعها في مجلد فرعي مثل `mudhakira/` لتجنب التعارض مع تطبيقاتك الأخرى.
   - إن كان مستودعًا منفصلاً: ضعها في الجذر مباشرة.
3. من إعدادات المستودع (Settings > Pages): فعّل GitHub Pages من الفرع `main` (والمجلد `/root` أو `/mudhakira` حسب اختيارك).
4. انتظر دقيقة، ثم افتح الرابط الذي يظهر لك، مثال:
   `https://username.github.io/mudhakira/`

## طريقة تثبيته كتطبيق على الهاتف

- **أندرويد (Chrome)**: افتح الرابط، ثم من القائمة (⋮) اختر "إضافة إلى الشاشة الرئيسية" أو ستظهر نافذة تلقائية لتثبيت التطبيق.
- **آيفون (Safari)**: افتح الرابط، اضغط على زر المشاركة، ثم اختر "إضافة إلى الشاشة الرئيسية".
- بعد التثبيت سيعمل التطبيق بأيقونته الخاصة وبدون شريط المتصفح، وسيبقى متاحًا حتى دون إنترنت (عدا زر التصدير الذي يحتاج تحميل مكتبات أول مرة فقط).

## ملاحظة تقنية

- تصدير PDF و Word يعملان بالكامل داخل المتصفح، بدون أي خادم خلفي.
- الصور التي تدرجها تبقى محفوظة داخل الصفحة طالما لم تُحدّث المتصفح (لا يوجد حفظ تلقائي دائم حاليًا) — يُفضّل تصدير عملك فور الانتهاء منه.
